# Logbook

This project is designed to assist the user in tracking various forms of entertainment they're consuming

## Categories

- Shows
- Movies
- Anime
- Manhwas

## Design - Pages

1. User login page
2. Home Page. (main)

    - Show all items
        - Top Shows, Reads
    - Filter categories
        - Movies, Dramas, Anime, Manga, Manhwa, Webtoon
        - Language - English, Chinese, Korean, etc.
        - Genre

## Item

Summary:
    - cover image
    - Title
    - Top 3 Labels

Details: (exapnd when clicked)
    - Cover image
    - Title
    - Labels
